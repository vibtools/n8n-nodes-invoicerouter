# Provider Template Pack Contract

Every provider template pack must include:

- `provider.template.ygit`
- `provider.csv`
- `email_list.csv`
- `invoice_results.csv`
- `provider.lifecycle.json`
- `README.md`

The `invoice_results.csv` header must match `template/status-writeback-columns.csv`. Template packs are onboarding assets; provider production support still requires provider documentation review and live proof.
