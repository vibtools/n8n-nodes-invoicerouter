# InvoiceRouter quickbooks Template

Use this provider pack with the v2.0.0 master workflow. Fill provider API/secrets in `provider.csv`, paste recipients in `email_list.csv`, and keep all output in `invoice_results`.

## Sandbox/live CSV variants

This scaffold pack includes `provider.sandbox.csv` and `provider.live.csv` so provider accounts can be activated per mode when a complete workflow/template is added.
