# Install the Freeze Pack into the Existing Repository

Extract the ZIP. Copy the contents of the `InvoiceRouter-Freeze-v1.0` folder into:

`D:\VibTools_Workspace\16_Workflow\InvoiceRouter`

This pack adds documentation and reference assets. It does not replace runtime source files.

Then run `COPY_LOCAL_NODE_ASSETS.cmd` from the repository root after copying that script there.
